== Managed Attributes
Managed attributes are attributes that can be created and used by the users on-demand to be used used to track data that is not common enough to be captured in a regular field. (see https://aafc-bicoe.github.io/dina-documentation/concepts-glossary#managed_attributes[DINA Glossary - Managed Attributes])

Managed Attributes are grouped by module. Each module has its own tab in the Controlled Vocabulary page:

Collection:: Main component in DINA that can be used for MaterialSample, CollectingEvent, Preparation, Transaction, etc.
Object Store:: Files uploaded to DINA that can be used as an attachment.
Sequencing:: Sequencing data tracked in DINA.
Agents:: Persons and organizations recorded in DINA.

[id=createAttr]
=== Creating Managed Attributes

. In the DINA Homepage, under the Controlled Vocabulary submenu, click on the `Controlled Vocabulary` option.

image::managed-attributes/Homepage.png[align="center"]

[start=2]
. In the Controlled Vocabulary page, choose the module you would like to make an attribute for (`Collection`, `Object Store`, `Sequencing`, or `Agents`).

image::managed-attributes/COsT.png[align="center"]

[start=3]
. In the same page, click on the `Create New` button.

image::managed-attributes/CreateNew.png[align="center"]

[start=4]
. In the Add Controlled Vocabulary Item page, select `Managed Attribute` in the `Controlled Vocabulary` field and fill out relevant data about the new attribute to be added. After doing so, click the `Save` button on the top right corner of the screen.

WARNING: The `Controlled Vocabulary`, `Target Data Component Type`, `Name`, and `Vocabulary Element Type` fields are mandatory.

image::managed-attributes/Fields.png[align="center"]

[start=5]
. Check that the information is correct. Note that this can be edited at any time (except for the `Target Data Component Type`, `Name`, and `Vocabulary Element Type` fields). +
If you wish to edit or delete the created attribute, you can do so through the buttons on the top right corner of the page.

image::EditDelete.png[align="center"]

[start=6]
. The created attribute can now be accessed in the Controlled Vocabulary page, under the tab of the module it was created for. The filters on the left side of the page (`Managed Attributes` and `Filter by Type`) can be used to narrow down the list.

image::managed-attributes/ListPage.png[align="center"]
