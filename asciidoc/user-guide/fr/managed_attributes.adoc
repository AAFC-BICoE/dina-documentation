[id=managedAttr]
== Attributs gérés
Les attributs gérés sont des attributs que les utilisateurs peuvent créer et utiliser au besoin pour consigner des données qui ne sont pas assez courantes pour être saisies dans un champ ordinaire. (voir https://aafc-bicoe.github.io/dina-documentation/concepts-glossary#managed_attributes[Glossaire de DINA - Attributs gérés])

Des attributs gérés peuvent être créés pour les composants suivants de DINA :

Collection:: Composant principal de DINA, qui peut être utilisé pour les échantillons de matériaux (MaterialSample), les événements de collecte (CollectingEvent), les préparations (Preparation), etc.
Dépôt d'objet:: Fichiers téléversés dans DINA qui peuvent être utilisés comme pièces jointes.
Transactions:: Transactions liées aux échantillons de matériaux qui sont suivies dans DINA.

[id=createAttr]
=== Créer des attributs gérés

. Dans la page d'accueil de DINA, sous le sous-menu Vocabulaire vérifié, cliquez sur l'option `Attributs gérés`.

image::managed-attributes/Homepage.png[align="center"]

[start=2]
. Dans la page Attributs gérés, choisissez l'objet pour lequel vous souhaitez créer un attribut (`Collection`, `Dépôt d’objet` ou `Transactions`).

image::managed-attributes/COsT.png[align="center"]

[start=3]
. Dans la même page, cliquez sur le bouton `Créer nouveau`.

image::managed-attributes/CreateNew.png[align="center"]

[start=4]
. Dans la page d'ajout d'attribut géré, remplissez les données pertinentes sur le nouvel attribut à ajouter. Ensuite, cliquez sur le bouton `Enregistrer` dans le coin supérieur droit de l'écran.

WARNING: Les champs `Nom`, `Type de composant des données cibles` et `Type d'élément de vocabulaire` sont obligatoires.

[start=5]
. Vérifiez que l'information est exacte. Notez qu'elle peut être modifiée en tout temps (sauf le champ `Nom`). +
Si vous souhaitez modifier ou supprimer l'attribut créé, vous pouvez le faire à l'aide des boutons dans le coin supérieur droit de la page.

image::EditDelete.png[align="center"]

[start=6]
. L'attribut créé est maintenant accessible dans la page de liste du type d'objet pour lequel il a été créé (`Collection`, `Dépôt d’objet` ou `Transactions`).

image::managed-attributes/ListPage.png[align="center"]
