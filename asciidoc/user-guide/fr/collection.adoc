[id=collection]
== Collection
Une https://aafc-bicoe.github.io/dina-documentation/concepts-glossary/#collection[collection] représente l'entité de plus haut niveau pouvant contenir des échantillons de matériaux.

[id=createCollection]
=== Créer une collection
. Du côté gauche de la page d'accueil de DINA, cliquez sur l'option `Collections` dans le sous-menu Collections

image::fr/collection/Homepage.png[align="center"]

[start=2]
. Dans la page Collections, cliquez sur le bouton `Créer`.

image::fr/collection/CreateNew.png[align="center"]

[start=3]
. Dans la page Ajouter une collection, ajoutez toute information pertinente sur votre collection. Ensuite, cliquez sur le bouton `Enregistrer` dans le coin supérieur droit de la page.

WARNING: Il est obligatoire de nommer votre collection.

[start=4]
. Vérifiez que l'information est exacte. Notez qu'elle peut être modifiée en tout temps. +
Si vous souhaitez modifier la collection, consulter les modifications ou supprimer la collection, vous pouvez le faire à l'aide des boutons dans le coin supérieur droit de la page.

image::fr/EditRevDelete.png[align="center"]

[start=5]
. La collection créée est maintenant accessible à partir de la page de liste.

image::fr/collection/ListPage.png[align="center"]
